## Execution Model

**Execution mode:** `sequential`
**Parallelism:** `none` (max concurrent phases: 1)
**Ordering:** ascending phase number, 1 → 57
**Commit granularity:** one commit per phase, on that phase's own branch

This project executes phases **strictly sequentially** in a single session. Phase
*n* begins only after phase *n−1* has been committed. No two phases are ever in
flight at once, on any machine, at any point in the plan.

The `**Dependencies:**` line on each phase therefore records a *semantic*
prerequisite — the phase whose output this phase reasons about — and never a
scheduling hint. The scheduler needs no edge to serialize two phases, because
the total order above already does.

**Shared files are expected, not conflicts.** Fifteen phase pairs touch a file
another pair also touches. Every one is a consequence of a documented decision,
and none is a race:

- `lib/strings.ts` — five phases (22, 27, 29, 43, 49). Copy lives in one table
  (`CLAUDE.md`: "Copy lives in `lib/strings.ts`"), and each stage commits its own
  keys in EN, CS and RU together. Six of the fifteen pairs are this file.
- `app/layout.tsx` — four phases (19, 20, 21, 56). The global chrome is built up
  across the shell stages: header, responsive frame, nav pill, then the football
  namespace. Five pairs.
- `app/globals.css` — four phases (15, 16, 20, 21). The token layer lands first
  (15, 16), the shell consumes it (20, 21). One unlinked pair.
- `docs/g1-checklist.md` — created by phase 2, completed by phase 53 when the
  gate is actually walked on a phone. One pair, now carried as an explicit edge.
- `playwright.config.ts` — created by phase 1, extended by phase 52 when the
  suites are wired. One pair.
- `lib/calendar/ics.ts` — the duration fallback (phase 8), then the namespace
  origins (phase 56). One pair.

Sequential execution makes each of these a plain read-modify-write against a
committed tree. A phase's "Hard constraints" file list remains binding: a phase
touches only the files it names, whether or not another phase names them too.
